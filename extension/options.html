Glint · 浏览器

让这里的标签页出现在 Glint 中

扩展已安装到当前浏览器配置文件。接下来，把它和桌面端连接起来。

  1. 复制当前扩展 ID

  2. 在桌面端注册

    运行 Glint.exe，打开“连接浏览器”，把 ID 粘贴到对应的 Chrome 或 Edge 输入框，再点击“保存并注册”。也可以从系统托盘菜单打开这个入口。

    无需管理员权限。更换 Glint.exe 的存放位置或扩展 ID 后，需要重新注册。

  3. 试一次标签页搜索

    点击下面的“重试连接”，然后按 Ctrl + Shift + Space 呼出 Glint。空查询应显示这个配置文件的标签页；输入标题或网址，按回车切换过去。

    如果你修改过热键，请使用桌面端中设置的组合键。

给这个配置文件起个名字（可选）

浏览器不会向扩展提供配置文件显示名称。这个本地标签会出现在搜索结果中，方便区分工作、个人等来源。

每个需要搜索的 Chrome / Edge 配置文件都要安装扩展。此扩展只读取标签页元数据，不读取网页正文。以后点击浏览器工具栏中的 Glint 图标，就能回到这里。
