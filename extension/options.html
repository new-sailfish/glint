Connection help

For your first connection, return to “Connect browser” in the Glint desktop app, select this browser, and check the connection. You can also open “Connect browser” from the Glint system tray menu.

When upgrading from an older version, run the desktop connection guide again and load the extension once from the new folder it provides. If you move Glint.exe, run the guide again to update the connection.

Closing this panel does not disconnect the extension. It connects automatically in the background; this panel does not need to stay open.

Install the extension in each Chrome / Edge profile you want to search. It processes tab titles and URLs, without reading page contents.
